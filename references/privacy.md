# Privacy and Confidentiality

## Career-source sensitivity

Career search materials may contain:

- home address
- phone number
- personal email
- employee identifiers
- compensation
- confidential business metrics
- internal product names
- customer names
- unreleased strategy
- proprietary processes
- manager feedback
- performance ratings

Treat source files as private unless the user says otherwise.

## Shareable artifacts

Before producing something intended to be shared publicly or with another person, remove or generalize:

- personal contact details not needed for the artifact
- employee IDs
- internal system IDs
- confidential customer names
- proprietary code names
- sensitive financial details
- private compensation data
- information marked confidential

## Evidence classifications

Use:

### Public
Safe for LinkedIn, public portfolio, public bio, or broadly shared resume.

### Recruiting-private
Appropriate for recruiters and interviewers but not public posting.

### Strategy-private
Useful for internal decision-making only.

## Performance reviews

Performance reviews are valuable evidence sources but should generally remain private.

Extract:

- validated scope
- achievements
- leadership evidence
- development themes

Do not reproduce private manager commentary in public artifacts unless the user explicitly requests it.

## Compensation documents

Use compensation documents to calculate strategy privately.

Do not expose exact current compensation in public-facing materials.

## Public examples

Any examples distributed with this skill should be synthetic or anonymized.

Do not use the original creator's personal career data as sample content.
